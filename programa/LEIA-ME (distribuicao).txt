ResetMissionsCOTW - versão 0.9.6 (Beta)
Reset de missões por mapa - theHunter: Call of the Wild
Criado por Sheeerpha
=========================================================

ESTA É UMA VERSÃO DE TESTE (BETA).
O programa foi criado por um jogador, não é oficial e pode ter falhas. Use com
atenção e, se algo der errado, avise na página do projeto (link no fim).


O QUE O PROGRAMA FAZ
--------------------
No jogo, só dá para resetar as missões apagando o arquivo de missões, e isso zera
as missões de TODOS os mapas. Este programa reseta as missões de UM mapa escolhido
(ou de vários) e mantém os outros mapas como estão.

Ele só altera o progresso das missões (arquivo missions_missiondata_adf). Perfil,
dinheiro, habilidades, armas, animais, troféus e o resto do save não são tocados.


ANTES DE ABRIR: A TELA AZUL "O WINDOWS PROTEGEU O COMPUTADOR"
-------------------------------------------------------------
Na primeira vez que você abrir o programa, o Windows provavelmente vai
mostrar uma tela azul dizendo "O Windows protegeu o computador".

ISSO É NORMAL. Acontece com todo programa que não tem uma "assinatura
digital", um certificado pago, comprado todo ano, que grandes empresas
usam. Como este é um programa gratuito, feito por um jogador, ele não
tem essa assinatura, e o Windows avisa por precaução. Não quer dizer
que o programa tenha vírus.

Como passar por ela:
1. Na tela azul, clique em "Mais informações" (o texto pequeno, logo
   abaixo da mensagem).
2. Vai aparecer o botão "Executar assim mesmo". Clique nele.
3. Pronto: o programa abre. Normalmente, essa tela só aparece na
   primeira vez.

Quer conferir antes? O código do programa é aberto: qualquer pessoa pode
ver exatamente o que ele faz em
https://github.com/Sheeerpha/ResetMissionsCOTW
e o programa é gerado automaticamente pelo próprio GitHub a partir desse
código. Baixe sempre da página oficial (GitHub ou Nexus Mods).


COMO USAR
---------
1. FECHE o jogo (o programa não deixa alterar nada com o jogo aberto).
2. Dê dois cliques em "ResetMissionsCOTW.exe".
   Se aparecer a tela azul do Windows, veja a seção acima.
   Sempre que o programa abre, aparece o aviso "Antes de começar". Na
   primeira vez, aparece também uma introdução rápida (dá para pular).
3. O programa encontra o seu save sozinho e mostra a lista de mapas com as
   missões concluídas, em andamento e o total.
   (Se não encontrar, clique em "Escolher pasta..." e aponte a pasta do save,
   que normalmente é: Documentos\Avalanche Studios\COTW\Saves\<número>)

   Tem save na Steam E na Epic, ou mais de uma conta? Escolha a plataforma
   em "Plataforma" e a conta na lista "Save". O save jogado mais recentemente
   já vem escolhido. O programa só mexe no save que estiver escolhido.
4. RECOMENDADO: clique em "Fazer backup do save completo" antes de tudo.
   Ele guarda uma cópia da pasta INTEIRA do save.
5. Clique no mapa que quer resetar (para escolher vários, segure Ctrl).
6. Clique em "Resetar missões do(s) mapa(s) selecionado(s)" e confirme.
7. O mapa fica verde, escrito "Missões resetadas". Abra o jogo e entre nesse
   mapa: as missões vão começar do zero.


BACKUPS
-------
Linha "Missões":
* Um backup do arquivo de missões é feito sozinho antes de cada reset.
* "Restaurar backup de missões...": desfaz um reset. A tabela mostra em amarelo
  o que vai mudar antes de você confirmar.
* São guardados até 50. Passando disso, o mais antigo é apagado sozinho, menos
  o primeiro (🔒), que é sempre mantido.

Linha "Save completo":
* "Fazer backup do save completo": copia a pasta inteira do save.
* "Restaurar save completo...": devolve o save inteiro de um backup. Atenção:
  todo o progresso feito depois daquele backup, em qualquer parte do jogo, é
  perdido. Antes de restaurar, o save atual também é guardado.
* São guardados até 5, com o primeiro (🔒) sempre mantido.
* "Abrir pasta": lá dentro há um arquivo explicando como restaurar à mão.

Os backups ficam em Documentos\.BKP_ResetMissions_Saves_COTW (pasta oculta),
separados por conta, nas pastas Backups_MISSIONS e Backups_SAVE.


VERIFICAÇÃO ANTES DE COMEÇAR
----------------------------
Ao abrir e antes de alterar o save, o programa confere se algo pode atrapalhar:
o jogo aberto, programas usando os arquivos do save (Steam, OneDrive, Google
Drive, Dropbox...), save dentro de pasta de nuvem e arquivos marcados como
"somente leitura". Tudo acontece só no seu computador: nada vai para a internet.
* Se estiver tudo certo, aparece só "✔ Verificação: tudo pronto".
* Se algo impedir, abre uma tela com botões: "Fechar Steam", "Fechar OneDrive",
  "Corrigir" (somente leitura) e "Verificar de novo". O programa NUNCA fecha
  nada sozinho nem à força: só quando você clica.
* O jogo nunca é fechado pelo programa: feche-o normalmente, pelo menu.


OUTROS AVISOS QUE PODEM APARECER
--------------------------------
* Faixa amarela "O Windows está bloqueando este programa..."
  Só aparece se você tiver ligado a proteção "Acesso Controlado a Pastas" do
  Windows Defender. Use os botões da própria faixa: "Como liberar (passo a
  passo)" explica tudo. Libere o programa no lugar onde ele vai ficar: se
  você mover o .exe de pasta depois, vai precisar liberar de novo.

* Steam Cloud / Epic Cloud
  Se ao abrir o jogo aparecer um aviso de conflito de arquivos na nuvem,
  escolha a versão LOCAL (a deste computador). Se escolher a da nuvem, o reset
  é desfeito.


IMPORTANTE
----------
* Não rode o programa de dentro do arquivo .zip: extraia a pasta antes.
* Funciona no Windows 10 e 11. Não precisa instalar nada.
* Idioma: o programa abre no idioma do seu Windows (português, inglês ou
  espanhol). Para trocar, use a lista com o globo 🌐 no canto de baixo.
* Tema: claro ou escuro, igual ao do seu Windows. Para trocar, use o botão
  "Tema escuro" / "Tema claro" no canto de baixo.
* "Como usar", no canto de baixo, mostra a introdução de novo.
* Testado com a versão Steam. Na Epic deve funcionar, mas ainda não foi testado.


ENCONTROU UM PROBLEMA?
----------------------
Abra um aviso ("Issue") na página do projeto no GitHub, com:
- um print da tela com a mensagem de erro;
- o que você fez antes do erro acontecer;
- o LOG: clique no botão "📄 Logs" do programa e mande o arquivo mais recente
  (ou use "Copiar detalhes" na janela de erro e cole no relato).
  O log fica em %LOCALAPPDATA%\ResetMissionsCOTW\logs (são guardados os 5 mais
  recentes) e não contém seu nome de usuário: os dados pessoais são mascarados.
